# 공룡 수 놀이 — 설치 안내

이 폴더는 휴대전화 홈 화면에 설치되는 웹앱(PWA)입니다. 한 번 열고 나면 인터넷 없이도 실행됩니다.

## 1. GitHub Pages에 올리기 (무료, 약 10분)
1. https://github.com 에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: `dino-math` (아무 이름이나 가능), **Public** 선택 → **Create repository**
3. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
4. 이 폴더 안의 파일과 `img` 폴더를 **전부** 드래그해서 올리기 (index.html, data.js, sw.js, manifest.json, icon-192.png, icon-512.png, img/ 폴더)
   - img 폴더는 폴더째 드래그하면 됩니다. 브라우저가 폴더 업로드를 지원하지 않으면 GitHub Desktop 앱을 쓰거나, 두 번에 나눠 올리세요.
5. 아래 **Commit changes** 클릭
6. 저장소의 **Settings** → 왼쪽 메뉴 **Pages** → Branch를 `main`, 폴더 `/ (root)` 선택 → **Save**
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다: `https://<아이디>.github.io/dino-math/`

## 2. 휴대전화에 설치
- **아이폰**: Safari로 주소 열기 → 아래 공유 버튼(네모+화살표) → **홈 화면에 추가**
- **안드로이드**: Chrome으로 주소 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 "앱 설치")

홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 실행되고, 이후에는 비행기 모드에서도 됩니다.

## 3. 나중에 내용을 바꾸고 싶을 때
파일을 다시 올리면(같은 이름으로 덮어쓰기) 1~2분 뒤 반영됩니다. 휴대전화에서는 앱을 완전히 닫았다가 두 번 정도 다시 열면 새 버전이 적용됩니다.

## 참고
- 진행 기록(어떤 공룡을 맞췄는지, 조각 수 단계)은 휴대전화 안에만 저장됩니다. 기기마다 따로 기록됩니다.
- 음성은 휴대전화 내장 한국어 TTS를 사용합니다. 첫 화면 **🔊 소리 확인** 버튼으로 확인할 수 있습니다.
